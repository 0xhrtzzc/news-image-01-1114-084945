# Entry for make.fun's news-image-01

`main.py` writes the entry image to `/output/entry.png`; the picture sits beside it as `entry.jpg` and is copied byte for byte.

The picture is a world map of Friday 13 November 2026 with 30 of the day's stories pinned where they happened, each pin joined to its headline: Nvidia's chief executive resigns, Microsoft's global outage, COP31 in Antalya, the Moscow and Tehran fronts, the markets, sport and weather. Drawn with Pillow from a public-domain world map; no model was used to draw it.
